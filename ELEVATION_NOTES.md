# Gyankunj IAS — Civil Services Evaluation Suite (v3.0 Elevated)

## What's Included in this Package:
1. **Full Next.js 16 + TypeScript + Tailwind + Supabase Platform**:
   - `app/quiz/[id]/page.tsx`: Bleeding-Edge UPSC CBT Quiz Engine v3.0 (Interactive statement True/False deduction, 50-50 option elimination with mathematical Expected Value, dual Exam/Tutor modes, 6-state OMR palette, keyboard shortcuts HUD, CSAT rough work scratchpad, and local+Supabase persistence).
   - `app/quiz/[id]/result/page.tsx`: 360° Post-Test Analytical Scorecard, Guesswork Calibration Matrix, Bilingual solution key, and One-Click Smart Remediation Drill (retry wrong/skipped only).
   - `app/dashboard/page.tsx`: Aspirant Study Sanctuary with Custom Smart Drill Builder, Pomodoro 25-min revision block, and GS Syllabus Mastery radar.
   - `app/quizzes/page.tsx`: Sectional and Full-Length Test Series Repository with instant search and discipline filters.
   - `app/admin/*`: Command Center, performance observation, live mock scheduler, and question paper synthesizer.
   - `lib/mockData.ts`: Authentic bilingual UPSC Prelims & CSAT questions for offline resilience and instant simulation.

2. **Standalone Zero-Dependency Preview (`gyankunj_civil_platform.html`)**:
   - Double-click or open in any web browser to run the entire elevated suite offline with zero dependencies!

## Quick Start (Next.js Application):
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
